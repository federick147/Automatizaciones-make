# Growth Loop Templates by Business Model

## B2B SaaS — Invite-Driven Viral Loop
```
User gets value from product
  → Invites teammate (collaboration feature)
    → Teammate activates
      → Team adopts product
        → Team pays / expands seats
          → Individual users spread to next company
```
**Friction points to fix:** invite flow friction, teammate onboarding, seat-upgrade prompts.

## Consumer App — Content/Social Loop
```
User creates content in product
  → Shares to social network
    → Viewer sees content with product attribution
      → Viewer signs up
        → Viewer creates content
          → Loop repeats
```
**Friction points to fix:** share experience, attribution/branding visibility, viewer onboarding.

## Marketplace — Supply/Demand Loop
```
Demand (buyers) attract supply (sellers)
  → Supply quality improves
    → More demand converts
      → Revenue enables supply incentives
        → More supply joins
```
**Friction points to fix:** supply quality, first transaction conversion, repeat usage.

## E-commerce — Paid + Retention Loop
```
Paid acquisition → First purchase
  → Post-purchase experience
    → Repeat purchase (LTV grows)
      → More revenue → reinvest in paid → scale
```
**Friction points to fix:** ROAS, post-purchase email flow, repeat purchase triggers.

## SEO/Content Loop
```
Users generate or consume content
  → Content ranks in search
    → Organic visitors find product
      → Convert to users
        → Generate more content/reviews
```
**Friction points to fix:** content quality, SEO optimization, conversion from organic traffic.

## Measuring Loop Velocity
- **Cycle time**: How long does one loop iteration take?
- **Conversion at each step**: % that progress to next step
- **Loop output**: New users generated per existing user per cycle
- **K-factor** (viral loops): K = invites_sent × invite_conversion_rate
  - K > 1 = exponential growth
  - K = 0.3–0.7 = meaningful supplement to other channels
